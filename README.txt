BIRTHDAY EXACT WEBSITE - 8 SCREENS

The project already contains the eight supplied screenshot images in assets/.

Flow:
1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8

Page 3 countdown: 20 -> 19 -> ... -> 0, then Page 4.
Page 5 countdown: 13 -> 12 -> ... -> 0, then Page 6.
The number smoothly changes and glows each second.

Run in VS Code:
1. Open this folder.
2. Right-click index.html.
3. Choose Open with Live Server.

Keyboard testing:
Right Arrow / Enter / Space = next
Left Arrow = previous
Esc = Page 1
